# Council

Standalone multi-AI chatroom environment bootstrapped as an offline Electron application.

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```
2. Launch the application:
   ```bash
   npm start
   ```

The window titled **Council** presents a two-column conversation view, with a seed input along the bottom. Messages are simulated locally for now; future phases will integrate live AI seats, memory systems, and RAM-disk orchestration.
